# Big Data: Прогнозирование стоимости недвижимости в Калифорнии (PySpark)

## О проекте
**Заказчик:** Аналитический отдел (внутренний проект).

**Бизнес-цель:** Обучить модель линейной регрессии для предсказания медианной стоимости недвижимости в Калифорнии (1990 г.), используя библиотеку машинного обучения Apache Spark MLlib. Оценить, как влияет добавление категориального признака (близость к океану) на точность предсказаний.

## Логика решения
*   Задача сводится к регрессии: предсказать медианную стоимость дома в жилом массиве.
*   Используется фреймворк Apache Spark для обработки данных и построения ML-моделей (Big Data).
*   Сравниваются две модели: со всеми признаками и только с числовыми.

## Данные
Датасет с информацией о жилых массивах Калифорнии за 1990 год (20 640 строк, 10 колонок).
*   **Признаки:** `longitude`, `latitude`, `housing_median_age`, `total_rooms`, `total_bedrooms` (есть пропуски — 1%), `population`, `households`, `median_income`.
*   **Категориальный признак:** `ocean_proximity` (близость к океану).
*   **Целевая переменная:** `median_house_value` (медианная стоимость дома).

## Задачи и методы
1.  **Инициализация Spark:** Создание локальной `SparkSession` для работы с DataFrame API.
2.  **EDA и препроцессинг:** 
    *   Обработка пропусков в `total_bedrooms` с помощью `Imputer` (стратегия — медиана).
    *   Кодирование категориального признака: `StringIndexer` + `OneHotEncoder`.
    *   Масштабирование числовых признаков: `StandardScaler`.
    *   Сборка признаков в вектор: `VectorAssembler`.
3.  **Пайплайн:** Использование `Pipeline` из PySpark ML для автоматизации всех этапов предобработки.
4.  **Моделирование:** Обучение двух моделей `LinearRegression`:
    *   **Модель №1:** Все признаки (числовые + категориальные).
    *   **Модель №2:** Только числовые признаки (без `ocean_proximity`).
5.  **Оценка:** Сравнение моделей по метрикам **RMSE, MAE, R2**.

## Стек
*   **Язык и Big Data:** Python, Apache Spark (PySpark), Spark MLlib.
*   **Препроцессинг:** `pyspark.ml.feature` (`Imputer`, `StringIndexer`, `OneHotEncoder`, `VectorAssembler`, `StandardScaler`).
*   **ML:** `pyspark.ml.regression.LinearRegression`.
*   **Данные:** Pandas (для загрузки и конвертации в Spark DataFrame).

## Результаты и интерпретация

**Сравнение моделей:**
| Модель | Признаки | RMSE | MAE | R2 |
| :--- | :--- | :--- | :--- | :--- |
| **Модель №1** | Все (числовые + `ocean_proximity`) | **68 839** | **49 832** | **0.64** |
| Модель №2 | Только числовые | 69 780 | 50 944 | 0.63 |

**Ключевые инсайты:**
*   **Категориальный признак работает:** Добавление `ocean_proximity` улучшило все метрики. RMSE снизился на 941 (1.3%), MAE — на 1 112 (2.2%), а R2 вырос на 0.01. 
*   **Влияние ограничено:** Улучшение небольшое (1–2%), что говорит о том, что близость к океану — значимый, но не главный фактор в ценообразовании. Основную предсказательную силу несут числовые признаки (доход, координаты, размер жилья).
*   **PySpark Pipeline:** Использование `Pipeline` позволило собрать все этапы предобработки (импутация, кодирование, масштабирование, сборка вектора) в единый воспроизводимый процесс.

**Бизнес-ценность:**
Проект демонстрирует навыки работы с большими данными и экосистемой Apache Spark. Построенная модель (R2 = 0.64) может использоваться как базовый инструмент для оценки недвижимости, а понимание важности категориальных признаков помогает аналитикам точнее настраивать модели.
