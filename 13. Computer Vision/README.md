# Определение возраста покупателей по фотографии

## О проекте

**Заказчик:** Сетевой супермаркет «Хлеб-Соль».

**Бизнес-цель:** Определить возраст покупателей по фотографии для двух задач:

1. Анализ покупок и таргетинг товаров, соответствующих возрастной группе.
2. Контроль добросовестности кассиров при продаже алкоголя (исключение продаж несовершеннолетним).

## Логика решения
*   Задача сводится к регрессии: модель принимает на вход изображение лица и предсказывает возраст (целое число).
*   Оценка качества осуществляется по метрике **MAE** (средняя абсолютная ошибка).
*   Целевой порог бизнеса — **MAE ≤ 8 лет**.

## Данные
В проекте использовался датасет от ChaLearn Looking at People.
*   **Объем:** 7 591 изображение (размеры от 60×60 до 3449×3449 пикселей, все RGB).
*   **Целевая переменная:** `real_age` (возраст от 1 до 100 лет).
*   **Особенности (выявлены на EDA):** Сильный дисбаланс классов. Взрослые (26–40 лет) составляют 33.8% выборки, пожилые (60+) — всего 6.9%. Это означает, что модель будет хуже определять возраст для крайних возрастных групп.

## Задачи и методы
1.  **EDA:** Исследование распределения возраста и размеров изображений.
2.  **Аугментация и препроцессинг:** Использование `ImageDataGenerator` для нормализации (`rescale=1./255`) и приведения размеров к 224×224×3.
3.  **Архитектура:** Использована предобученная нейросеть **ResNet50** (Transfer Learning, разморожены все слои). 
    *   Выходной слой: `GlobalAveragePooling2D` + `Dense(1)` с активацией `ReLU` (возраст не может быть отрицательным).
4.  **Обучение:** Оптимизатор `Adam`, функция потерь `MSE`, метрика `MAE`.
5.  **Колбэки:** Использованы `EarlyStopping` (с восстановлением лучших весов) и `ReduceLROnPlateau` для управления скоростью обучения.

## Стек
*   **Язык и данные:** Python, Pandas, NumPy, PIL.
*   **Deep Learning:** TensorFlow/Keras (Sequential, GlobalAveragePooling2D, Dense).
*   **Модели:** ResNet50 (Transfer Learning).
*   **Визуализация:** Matplotlib, Seaborn.

## Результаты и интерпретация

**Качество модели:**
*   **Test MAE:** **5.8244** (целевой порог ≤ 8 выполнен с запасом).
*   **Время обучения:** ~40 секунд на эпоху.
*   **Сходимость:** Порог MAE ≤ 8 был пробит уже на **4-й эпохе**. Обучение остановлено на 28-й эпохе благодаря `EarlyStopping` (модель восстановила веса с лучшей 20-й эпохи).

**Ключевые инсайты и ограничения:**
*   **Быстрая адаптация:** Благодаря предобученным весам ResNet50 модель показала отличную сходимость. `ReduceLROnPlateau` дважды снижал learning rate, помогая преодолеть плато.
*   **Контроль переобучения:** Разрыв между train и val MAE рос к концу обучения, но `EarlyStopping` сработал вовремя, сохранив лучшую модель (val_mae ~ 5.8–6.0).
*   **Бизнес-ограничение:** Ошибка +/- 6 лет приемлема для таргетинга товаров, но **несет риски для контроля продажи алкоголя**: 14–15-летний подросток может быть ошибочно принят за 20–22-летнего.

**Рекомендации по улучшению (для production):**
1.  Включить аугментацию данных (отражения, повороты) для повышения обобщающей способности.
2.  Использовать взвешенную функцию потерь (class weights) для компенсации дисбаланса и улучшения точности на пожилых (60+) и детях (0–12).
3.  Сократить количество эпох (до 20) и уменьшить `patience` для экономии ресурсов, так как цель достигается очень быстро.
