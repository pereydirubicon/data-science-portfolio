# HR-аналитика: прогнозирование удовлетворенности и оттока сотрудников

## О проекте
**Заказчик:** HR-отдел компании «Работа с заботой».

**Бизнес-цель:** Оптимизировать управление персоналом через прогнозирование ключевых HR-показателей. Выявить сотрудников, склонных к увольнению, и определить факторы, влияющие на их удовлетворенность, чтобы снизить текучесть кадров.

## Логика решения

В проекте решаются две задачи:
1.  **Регрессия:** Предсказать уровень удовлетворенности сотрудника работой (`job_satisfaction_rate`). Метрика — **SMAPE** (целевой порог ≤ 15%).
2.  **Классификация:** Предсказать факт увольнения сотрудника (`quit`). Метрика — **ROC-AUC** (целевой порог ≥ 0.91).
Данные для обеих задач содержат характеристики сотрудников (отдел, уровень, нагрузка, стаж, зарплата и т.д.).

## Данные
Три набора данных: `train_satisfaction`, `test_features` и `test_target_satisfaction` (для задачи 1), а также `train_quit` и `test_target_quit` (для задачи 2).
*   **Признаки:** `dept` (отдел), `level` (уровень), `workload` (загруженность), `employment_years` (стаж), `last_year_promo` (повышение), `last_year_violations` (нарушения), `supervisor_evaluation` (оценка руководителя), `salary` (зарплата).
*   **Целевые переменные:** `job_satisfaction_rate` (регрессия), `quit` (классификация).
*   **Особенность:** В тренировочной выборке для задачи 2 (`train_quit`) был значительный дисбаланс классов (74.7% / 25.3%), который устранен с помощью `SMOTENC`.

## Исследовательский анализ (EDA) и портрет уволившегося
На основе анализа данных был составлен **портрет сотрудника с высоким риском увольнения**:
*   **Должность:** Junior в отделе закупок (purchasing).
*   **Стаж:** 1 год (увольняются в 61.2% случаев).
*   **Нагрузка:** Низкая (low) — отсутствие задач демотивирует (39% увольнений).
*   **Оценка руководителя:** 1 балл (минимальная, 40.4% увольнений).
*   **Карьера:** Без повышения за последний год.
*   **Зарплата:** В среднем на 37.1% ниже, чем у оставшихся (25 768 против 40 952 руб.).
*   **Удовлетворенность:** У уволившихся в среднем 0.39 против 0.61 у оставшихся (различие статистически значимо, p-value < 0.05).

## Задачи и методы
1.  **Предобработка:** Обработка пропусков (`SimpleImputer`), кодирование категориальных признаков (`OneHotEncoder`, `OrdinalEncoder`), масштабирование (`MinMaxScaler`, `StandardScaler`).
2.  **Пайплайн:** Использование `Pipeline` и `ColumnTransformer` для автоматизации. Для задачи классификации использован `ImbPipeline` с `SMOTENC` для борьбы с дисбалансом.
3.  **Моделирование:** 
    *   Для регрессии: `HistGradientBoostingRegressor` (лучший результат).
    *   Для классификации: `HistGradientBoostingClassifier` (лучший результат). 
    *   Подбор гиперпараметров через `RandomizedSearchCV` (5 фолдов).

## Стек
*   **Язык и данные:** Python, Pandas, NumPy, SciPy.
*   **Препроцессинг:** Scikit-learn (`Pipeline`, `ColumnTransformer`, `SimpleImputer`, `OneHotEncoder`, `OrdinalEncoder`, `Scaler`), Imbalanced-learn (`SMOTENC`, `ImbPipeline`).
*   **ML:** Scikit-learn (`HistGradientBoostingRegressor`, `HistGradientBoostingClassifier`, `LogisticRegression`, `RandomizedSearchCV`).
*   **Визуализация:** Matplotlib, Seaborn, SHAP.

## Результаты и интерпретация

**Задача 1 (Регрессия — Удовлетворенность):**
*   Лучшая модель: **HistGradientBoostingRegressor**.
*   **SMAPE:** 11.69% на train, **10.66% на test** (целевой порог ≤ 15% выполнен).
*   Ключевые факторы: оценка руководителя (наибольшее влияние), уровень должности, зарплата.

**Задача 2 (Классификация — Увольнение):**
*   Лучшая модель: **HistGradientBoostingClassifier**.
*   **ROC-AUC:** 91.99% на train, **92.62% на test** (целевой порог ≥ 0.91 выполнен).
*   В модель добавлен новый признак `job_satisfaction_rate`, предсказанный первой моделью, что повысило качество.

**Ключевые бизнес-рекомендации:**
1.  **Усилить адаптацию новичков:** Сотрудники со стажем 1 год увольняются в 61% случаев. Необходима программа наставничества и пересмотр онбординга.
2.  **Мониторинг удовлетворенности:** Внедрить регулярные опросы (например, ежеквартально). Сотрудники с удовлетворенностью ниже 0.4 — критическая группа риска.
3.  **Работа с руководителями:** Низкая оценка руководителя напрямую связана с увольнением. Требуется обучение менеджеров и внедрение системы оценки их работы.
4.  **Карьерный рост и нагрузка:** Отсутствие повышения и низкая загруженность демотивируют. Пересмотреть систему распределения задач и карьерных треков.

**Бизнес-ценность:**
Модели позволяют HR-отделу заранее выявлять сотрудников из группы риска (по удовлетворенности и вероятности увольнения) и принимать точечные меры по их удержанию, что снижает затраты на найм и адаптацию новых людей.
