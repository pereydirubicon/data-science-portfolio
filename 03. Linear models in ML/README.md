# Прогнозирование удоя и вкуса молока

## О проекте
**Заказчик:** Фермер, владелец молочного хозяйства «Вольный луг».

**Бизнес-цель:** Разработать две прогнозные модели для минимизации рисков при закупке коров у «ЭкоФермы» и обеспечения планового развития хозяйства.

## Логика решения
* **Регрессия:** предсказать удой коровы — целевой критерий не менее 6000 кг в год.
* **Классификация:** предсказать вероятность вкусного молока — бинарный признак.
* Итоговый отбор коров — по двум критериям одновременно: прогноз удоя ≥ 6000 кг (с учётом доверительного интервала) **и** вкусное молоко.
* Для коров «ЭкоФермы» отсутствуют параметры корма (`eke`, `protein_g`, `spo`) — по условию их увеличивают на 5% от средних значений, а целевые признаки предсказываются моделями.

## Задачи и методы
1. **ETL и препроцессинг:** приведение названий колонок к snake_case, устранение неявных дубликатов, удаление явных дубликатов и аномальных значений.
2. **EDA:** анализ категориальных (столбчатые и круговые диаграммы) и количественных (ящик с усами, гистограмма, проверка нормальности) признаков.
3. **Корреляционный анализ:** Phik-корреляции и диаграммы рассеяния с линиями тренда по категориям.
4. **Регрессия (3 итерации):**
   * **Модель 1:** базовый набор признаков (`eke`, `protein_g`, `spo`, `breed_cow`, `type_pasture`, `breed_dad_cow`, `age`).
   * **Модель 2:** исключение нелинейности — `spo` → бинарный `spo_cat` (граница 0.90), `eke` → `eke_square`.
   * **Модель 3:** добавлен новый признак `dad_name` (имя отца из `ferma_dad`).
   * Кодирование `OneHotEncoder`, масштабирование `StandardScaler`, метрики R², MSE, RMSE, MAE, анализ остатков.
5. **Классификация:** логистическая регрессия с `OneHotEncoder` и `StandardScaler`, подбор порога через перебор (`precision_recall_curve` / ручной перебор) для минимизации FP.
6. **Прогноз для `cow_buy`:** заполнение отсутствующих признаков корма (+5% к средним), предсказание удоя и вкуса, отбор коров по двум критериям.

## Стек
* **Язык и данные:** Python, Pandas, NumPy, SciPy.
* **Препроцессинг:** Scikit-learn (`OneHotEncoder`, `StandardScaler`, `train_test_split`).
* **ML:** Scikit-learn (`LinearRegression`, `LogisticRegression`).
* **Метрики:** `r2_score`, `mean_squared_error`, `mean_absolute_error`, `accuracy_score`, `recall_score`, `precision_score`, `precision_recall_curve`, `confusion_matrix`.
* **Корреляции:** Phik.
* **Визуализация:** Matplotlib, Seaborn.

## Результаты и интерпретация

**Регрессия (прогноз удоя):**

* **Лучшая — Модель 3:** R² 0.80, RMSE 192, MAE 148. Добавление `dad_name` и устранение нелинейности дали прирост качества.
* **Доверительный интервал ошибки (95%):** [−396; +345] кг.
* **Подходящих коров по удою (с учётом интервала ≥ 6000 кг):** 15 из 20.

**Классификация (прогноз вкуса):**
* **Базовая модель (порог 0.5):** Accuracy 0.64, Recall 0.85, Precision 0.65, FP = 43.
* **Порог 0.82:** Precision = 1.00, FP = 0, Recall = 0.074 — слишком строго, ни одна корова не проходит.
* **Порог 0.68 (запасной):** Precision = 0.85, FP = 6, Recall = 0.37 — **5 коров** с вкусным молоком.

**Итоговый отбор (удой ≥ 6000 + вкусно):**
* **4 коровы** с индексами **[0, 6, 9, 16]** — рекомендованы фермеру при готовности к умеренному риску.
* Риски: ~5% — недостаточный удой, ~14.6% — невкусное молоко.

**Ключевые инсайты:**
* **Удой** сильнее всего зависит от возраста коровы (связь 0.998), затем от питательности корма (0.72), жирности молока (0.71) и сахаро-протеинового соотношения (0.66).
* **Вкус молока** сильнее всего связан с сахаро-протеиновым соотношением (0.58), затем с питательностью корма (0.28) и типом пастбища (0.25).
* **Мультиколлинеарность** между питательностью корма, сахаро-протеиновым соотношением и жирностью молока (0.6–0.72) — учтена при отборе признаков.
* **Проблемы в данных:** 25% коров недополучают питание (ниже нормы), 41.5% молока невкусное, подозрительно одинаковая белковость — возможна стандартизация при вводе данных.

**Бизнес-ценность:**
Модели позволяют фермеру принимать решение о закупке коров на основе прогноза двух ключевых параметров. При консервативном подходе (порог 0.82) — покупать не рекомендуется; при умеренном риске (порог 0.68) — рекомендованы 4 коровы, что снижает вероятность убытков от некачественного молока и низкого удоя.
