# Исследование сервиса аренды самокатов

## О проекте
**Заказчик:** сервис аренды самокатов GoFast.

**Бизнес-цель:** проанализировать данные сервиса и проверить гипотезы, которые помогут бизнесу вырасти, а также решить две прикладные задачи — по промокодам и push-уведомлениям.

## Логика решения
* **Анализ данных:** объединить пользователей, поездки и тарифы, посчитать помесячную выручку по каждому клиенту.
* **Проверка 3 гипотез** о различиях между подписчиками и неподписчиками (время поездки, расстояние, выручка) + теоретический вопрос о тесте «до/после».
* **Промокоды:** подобрать минимальное число промокодов, чтобы с вероятностью ~95% получить не менее 100 продлений подписки.
* **Уведомления:** оценить вероятность, что из 1 млн push-уведомлений их откроют не более 399.5 тыс. пользователей.

## Данные

**Особенности:** 8 городов, распределены равномерно; пользователи 12–43 лет (в среднем 25); 54.4% без подписки, 45.6% с подпиской; в поездках найдено 95 аномалий (длительность < 1 мин при расстоянии 4+ км) — оставлены как незначимые.

## Задачи и методы
1. **ETL и предобработка:** приведение типов (дата → datetime), удаление 31 явного дубликата в таблице пользователей, добавление месяца, округление длительности «потолком».
2. **EDA:** распределение по городам, подпискам, возрасту, расстоянию и длительности поездок.
3. **Объединение данных:** merge трёх таблиц, разделение на две выборки — с подпиской и без.
4. **Агрегация и выручка:** сводная таблица «пользователь × месяц» (суммарное расстояние, число поездок, суммарное время), расчёт помесячной выручки по формуле тарифа.
5. **Проверка гипотез:** t-тест Стьюдента для независимых выборок (с поправкой на неравенство дисперсий), односторонние альтернативы; для «до/после» — парный t-тест.
6. **Распределения:** биномиальное распределение и его нормальная аппроксимация для промокодов и уведомлений, построение графиков с зонами выполнения/невыполнения плана.

## Стек
* **Язык и данные:** Python, Pandas, NumPy.
* **Статистика:** SciPy (`ttest_ind`, `ttest_1samp`, `ttest_rel`, `norm`), `math` (sqrt, factorial).
* **Визуализация:** Matplotlib.

## Результаты и интерпретация

**Выручка:**
* Пользователи без подписки приносят больше суммарной выручки, чем подписчики.
* Резкий спад выручки — в феврале; пик у free — декабрь (193 406 ₽), у ultra — май (148 641 ₽).

**Проверка гипотез:**
* **Подписчики проводят в поездках больше времени, чем пользователи без подписки** — разница статистически значимая (p-value близко к нулю). Подписчики «выгоднее» для компании.
* **Средняя поездка подписчика не длиннее 3130 метров** — подтвердили: данные не показывают превышения (p-value = 0.92, среднее ~3115 м). Износ самокатов в норме.
* **В месяц подписчик приносит больше выручки, чем пользователь без подписки** — разница статистически значимая (p-value близко к нулю; в среднем 363 ₽ против 329 ₽).
* **Гипотеза «до/после обновления серверов»** — здесь нужен парный t-тест: сравниваем обращения в поддержку у одних и тех же пользователей до и после обновления, проверяя, что после стало меньше.

**Промокоды:**
* Ситуация описывается биномиальным распределением: рассылаем промокоды, каждый пользователь независимо продлевает подписку с вероятностью 10%.
* Чтобы план «не менее 100 продлений» выполнялся с вероятностью 95% (риск невыполнения ~5%), нужно разослать **1169 промокодов**. В среднем это даст ~117 продлений.

**Уведомления:**
* Рассылаем 1 млн уведомлений, каждое открывают с вероятностью 40%.
* В среднем откроют около 400 тыс. Вероятность, что откроют **не больше 399.5 тыс.**, — примерно **15%**. То есть с вероятностью **85%** открытий будет больше — хороший сценарий для компании.

**Ключевые инсайты:**
* Подписка ultra делает клиента вовлечённее и прибыльнее в расчёте на человека, но суммарно сегмент без подписки пока приносит больше — просто потому, что таких клиентов больше.
* Поездки подписчиков укладываются в безопасный для самокатов километраж — износ в норме.
* Значит, компании выгодно переводить клиентов на подписку: каждый подписчик приносит больше денег.

**Бизнес-ценность:**
Результаты подтверждают, что подписка — выгодный для компании продукт: подписчики дольше ездят и приносят больше выручки в месяц. Это обосновывает акции по переводу пользователей на ultra. Расчёты по промокодам и уведомлениям дают маркетингу готовые параметры кампаний с управляемым уровнем риска.
